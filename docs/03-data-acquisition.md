# 数据采集方案

## 1. 一人可执行的数据规模

当前清单覆盖 Apple、华为、小米/REDMI、荣耀、OPPO、vivo/iQOO、一加、三星、realme、魅族十个品牌。只纳入品牌官网当前目录中、优先为最近两年发布的型号；官网未明确写发布日期时，字段保持为空并进入质量报告，不能伪造日期。每个内存版本独立建档；每个平台最多保留一个经人工确认的官方旗舰店商品链接。

先完成 80–120 个型号、200–350 个内存版本，再逐步扩容。课程里的“几百款”最好解释为几百个可购买版本，而不是强行收集几百个型号后降低真实性。

## 2. 数据源优先级

1. 品牌官网规格页：发布日期、CPU、屏幕、相机、电池、尺寸、重量、发售价；
2. 品牌官方新闻稿/发布会页：官网规格页缺失的发售日期与首发价；
3. 京东、天猫、拼多多官方旗舰店公开商品页：对应 SKU 的公开价格；
4. 人工复核：店铺主体、内存版本、地区、库存、资格标签与截图证据。

第三方评测可用于解释体验，但不覆盖官方硬件字段。

产品图优先读取官网页面明确声明的 `og:image` 或 `twitter:image`，并同时保存来源页面。不要把相机样张、代言人照片、配件图或 AI 示意图当成手机产品图；无法确认时留空并人工补录。

## 3. 标准采集流程

1. `config/official_catalog_sources.csv` 维护品牌、型号和官网来源页。
2. `collect_catalog.py` 读取 `robots.txt` 后低频采集，自动保存网页文本证据、解析参数和内存组合，并幂等写入 SQLite。
3. 禁止自动抓取的官网使用 `manual_verified_supplement.csv` 人工核验导入；报告中与自动采集数据分开标记。
4. `generate_price_queue.py` 为每个版本生成京东、天猫、拼多多三条任务和平台搜索入口。
5. 人工打开平台，确认店铺、商品、SKU 与地区；`capture_price.py` 保存公开页面文字和截图。若出现验证码或无法确认 SKU，保持 `pending`。
6. 在队列中分别填写普通价、公开活动价、国补展示价、百亿补贴价、审核人与证据路径。
7. 先把人工确认的“平台 + 品牌 + 精确店铺名”写入 `config/official_store_whitelist.csv`；`import_reviewed_prices.py --dry-run` 校验平台域名、官方店白名单、审核人、价格范围和证据，通过后正式入库。
8. `audit_data_quality.py` 输出字段覆盖率、品牌分布、两年窗口和缺失版本问题；抽查后再用于推荐。

## 4. 更新频率

- 手机规格与发售价：首次建档后每月核查在售状态；
- 普通售价：每周一次；大促期间每天一次；
- 国补和百亿补贴：活动规则变化快，展示时明确采集时间与资格条件；
- 商品下架、验证码、地区不支持、SKU 不匹配均保存失败状态，不写入价格 0。

## 5. 合规与质量控制

遵守 robots.txt、平台服务条款和合理请求频率；只采集公开商品信息，不收集用户数据，不破解登录/验证码，不并发轰炸站点。旗舰店必须人工核验，域名、店铺名和商品 ID 进入白名单。随机抽样计算字段准确率；低于 95% 的解析规则暂停自动入库。

建议每条数据具有 `source_url`、`source_checked_at`、`data_quality` 三项来源元数据。无法确认的字段留空，这是比猜一个值更高质量的做法。

## 6. 当前实际结果（2026-09-16）

- 官网来源清单：72 个页面；最近一次完整采集 54 个页面成功，18 个页面因 `robots.txt` 或失效地址拒绝；
- 入库规模：10 个品牌、203 款在售机型、394 个内存版本；
- 字段覆盖率：CPU 52.2%、屏幕尺寸 49.3%、刷新率 47.8%、主摄 46.3%、电池 52.2%、重量 42.4%、可信官网产品图 44.3%；
- 已审核真实平台商品与价格快照：3 条（京东 2 条、天猫 1 条），均带证据；演示快照不计入有效指标；
- 至少有一平台已审核价格的版本：3 个；三平台齐全版本：0 个；
- 三平台逐 SKU 待办队列：1182 条，按缺口与发布时间排序，并可断点续做；
- 仍有 77 款未解析到明确内存版本、173 款发布日期未由官网确认，均保持为空并进入质量缺口；
- 演示商品链接与演示价格不参与推荐的有效价格统计。

图片覆盖率仅统计通过 URL 质量规则的官网产品图；Logo、SVG 图标、头像、二维码和占位图会被清空并进入待补充状态，因此该指标宁缺毋滥。

本轮新增了离线证据重解析流程，可对约 66 MB 已保存官网原始页面重新运行解析规则，网络请求数为 0；同时修正了“独立列出 RAM/ROM”“同一 RAM 对应多个 ROM”以及双电芯等效容量的保守解析。每次正式入库前均自动复制 SQLite 备份。

最新结果以 `data/reports/data-quality-latest.json` 为准。电商价格只有人工完成登录态核验和留证后才计入“有效价格快照”。
