## 本轮改进

1. 官网离线重解析器合并全部历史报告，为每款手机选取最新成功证据；重解析 145 款，网络请求数为 0。
2. 参数覆盖率得到真实提升：屏幕尺寸 48.3%→49.3%，刷新率 41.4%→48.8%，主摄 44.3%→50.7%，重量 41.4%→50.2%。其中本轮新增了对官网“标签换行 + 颜色差异值”和“2 亿像素”写法的保守解析。
3. 清除 Logo、SVG 图标、导航栏缩略图、微信页脚图等错误图片。图片覆盖率下降到 44.3%，但留下的图片更可信。
4. 生成 1182 条“版本 × 平台”任务；队列按数据缺口与发布时间排序，再次生成会保留已有链接与审核进度。
5. 增加商品候选评分、页面留证、离线价格重解析、单条证据审核和幂等入库工具。
6. 官方店从“名称包含旗舰店”升级为“平台 + 品牌 + 精确店铺名”白名单校验。
7. 新增 iQOO 15 16GB+256GB 天猫证据：优惠前 4899 元、券后 4319.1 元；“政府补贴10%”未显示确定金额，因此没有写成确定国补价。
8. SQLite 维护脚本提交后自动执行 WAL 检查点，确保 GitHub 数据库与本地查询一致。

## 数据可信度边界

- 演示快照不计入真实价格指标；
- 自动解析结果只进入 `needs_review`，通过店铺白名单、型号、版本、价格和证据校验后才能标记 `approved`；
- 国补百分比不换算成页面实显国补价，资格由用户在结算页自行确认；
- 无法确认的参数、日期和价格保持为空，不使用猜测值补齐；
- 搜索页或商品页出现登录、滑块、验证码、访问频繁时记录 `blocked`，不绕过平台验证。
